# Failure lab

Generated by `node tools/failure-lab.js`. Every number here comes from
that script; nothing in this file is written by hand.

**What this exercises.** The lab runs the service logic in-process on
`MemoryStore` with a virtual clock — the same signature check, tx_id
lookup, expiry arithmetic and holdings transaction the deployed function
runs. **It does not exercise the real SMS network, Firestore, or a
broker.** No packet crosses a radio and no transaction reaches Google.

A **first-time decision** is a delivery the server decided and wrote to
the ledger. Only the filled ones sold anything: the rest are terminal
refusals that kept their tx_id but moved no shares. Deliveries stopped
before the ledger (forged, or a tx_id conflict) are counted separately
again, because they never became an order at all.
