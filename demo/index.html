Turn the phone's data off and place an emergency sell. The order leaves as a signed SMS, the security engine checks it, the sell executes, and a confirmation SMS comes back. Everything below runs in your browser.

    This page is a simulation of the server checks, not the backend running in your browser. The checks below are a second implementation in JavaScript that mirrors the real one in firebase/functions/, in the same order, so you can watch each one decide. Real: the TRX2 packet format and HMAC-SHA256 signing (your browser's Web Crypto), the signature check, the tx_id ledger and its exactly-once replay, expiry, the holdings and per-stock emergency limit, and the optional price floor.
    What is simulated: the SMS hop, Firestore, and the exchange. Fills are at the last price, the ledger lives in this tab and resets with the page, and no broker is involved. On real phones the same packet goes out as an actual SMS. The guarantees this page shows are tested for real in the repo's backend test suite — see the README for which test covers which button.
